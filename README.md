# Coxpit

Stuursimulator voor beginnende stuurlieden in de roeisport: geef commando's aan een virtuele ploeg en stuur een C4x+ zonder roerstandindicatie.

**Proberen:** https://petervanwilgen.github.io/coxpit/ (Chrome of Edge; sta de microfoon toe voor spraak).

Status: prototype v0.2 — bovenaanzicht, perfecte ploeg, commando's aanklikken of uitspreken, nabespreking van timing en roergebruik.

Spraakherkenning gebruikt de Web Speech API van de browser; de audio gaat daarbij naar de spraakdienst van de browserleverancier.
